# CelebrAI — Every Celebration, Thoughtfully Planned

CelebrAI is an intelligent celebration and event planning web application that helps hosts organize weddings, birthdays, and community gatherings. By converting high-level event criteria—such as event type, guest count, budget, date, and personal preferences—into an actionable, structured workspace, CelebrAI provides budget breakdowns, chronological timelines, vendor checklists, and personalized ideas.

📦 **Source Code:** [https://github.com/souvikpal77/celebrai-event-planner](https://github.com/souvikpal77/celebrai-event-planner)

## Overview

Planning a memorable event often involves balancing multiple moving parts simultaneously. CelebrAI serves as an interactive planning assistant that bridges creative celebration concepts with practical logistical execution.

Users begin on a public landing page, step through an event creation flow where they define their celebration parameters, and receive a customized plan generated by Google Gemini. The resulting plan is loaded into a modular dashboard where hosts can track their finances, schedule milestones, coordinate vendors, explore tailored concepts, and manage day-of logistics.

---

## Problem

Organizing events presents several common difficulties for individuals and community organizers:

- **Unclear Budget Allocation:** Estimating realistic expense categories across venue, catering, decor, and photography without losing visibility into overall spending.
- **Fragmented Timelines:** Keeping track of sequential deadlines and planning milestones months or weeks in advance.
- **Vendor Tracking Overhead:** Managing multiple vendor categories, inquiry stages, contracts, and notes across disparate notes and spreadsheets.
- **Generic or Unfocused Ideas:** Finding creative themes, decor, and entertainment ideas that directly align with specific guest sizes, dietary considerations, and budget realities.
- **Event-Day Coordination:** Bridging pre-event planning with an hour-by-hour run-of-show schedule for the day itself.

---

## Solution

CelebrAI addresses these pain points by pairing generative AI for structured content generation with deterministic logic for calculations:

- **AI-Assisted Plan Drafting:** Leverages Google Gemini to formulate event concepts, expense category proposals, timeline milestones, vendor requirements, and celebration ideas tailored to the user's inputs.
- **Deterministic Budget Arithmetic:** Calculations for total budget, allocated amounts, remaining balances, and over-budget warnings are executed purely in TypeScript, ensuring absolute mathematical accuracy without relying on LLM arithmetic.
- **Unified Workspace:** Brings budgets, timelines, vendor statuses, creative ideas, and day-of schedules into a single responsive interface.
- **Built-in Fallback Engine:** Features a server-side deterministic planning engine that ensures the user journey remains uninterrupted even if external API calls encounter temporary network or rate limits.

## Core Features

- **AI-Generated Event Plans:** Generates cohesive plans based on event type, guest size, budget, target date, location, theme, and dietary needs.
- **Budget Breakdown & Tracking:**
  - Category-based cost allocations with real-time recalculation.
  - Dynamic controls to add, edit, or delete expense items.
  - Visual remaining balance indicator and immediate over-budget warning alerts when allocations exceed the target budget.
  - Support for multi-currency formatting (including INR, USD, EUR, GBP, AUD, CAD).
- **Timeline & Milestone Planning:**
  - Chronological planning checklists organized from months before the event to the final days.
  - Priority markers (High, Medium, Low) and completion status toggles.
  - Inline milestone creation and task status tracking.
- **Vendor Checklist & Status Pipeline:**
  - Categorized vendor tracking (Venue, Catering, Decor, Photography, AV/Sound, Entertainment).
  - Four-stage pipeline: *To Contact*, *Contacted*, *Shortlisted*, *Booked / Confirmed*.
  - Persistent notes field for storing vendor contact details, quotes, and contract terms.
- **Personalized Celebration Ideas:**
  - Curated recommendations across themes, decor, food, guest experiences, and entertainment.
  - Contextual "Why it fits your celebration" rationales for each recommendation.
  - Dedicated "Regenerate Ideas" action to discover fresh concepts while retaining existing event data.
- **Event-Day Run-of-Show Itinerary:**
  - Structured hourly schedule covering vendor load-in, guest arrival, main celebrations, dining, and farewells.
  - Interactive item completion checkboxes and custom itinerary slot creation.
- **Sample Event Templates:** Instant pre-loaded templates for weddings, birthdays, and community events to explore application capabilities immediately.
- **Session Persistence:** Event state and manual adjustments automatically save to browser `localStorage`, ensuring data persists across page reloads.

## How It Works

```
┌─────────────────┐       ┌─────────────────┐       ┌──────────────────┐
│   User Enters   │       │   Express API   │       │  Google Gemini   │
│  Event Details  │ ────> │   Backend       │ ────> │  (gemini-3.8-    │
│  & Constraints  │       │  (/api/plan)    │       │   flash)         │
└─────────────────┘       └─────────────────┘       └─────────┬────────┘
                                                              │
                                                              ▼
┌─────────────────┐       ┌─────────────────┐       ┌──────────────────┐
│   Interactive   │       │  Deterministic  │       │ Structured JSON  │
│   Dashboard     │ <──── │  Validation &   │ <──── │ Generation /     │
│   Workspace     │       │  Sanitization   │       │ Fallback Engine  │
└─────────────────┘       └─────────────────┘       └──────────────────┘
```

1. **Event Setup:** The host fills out the event setup form with celebration type, budget, guest count, location, target date, theme, and optional dietary/accessibility considerations.
2. **Backend Processing:** The Express backend receives the request, validates all fields against strict length and numeric boundaries, and forwards the structured prompt to the Gemini API.
3. **Structured Response:** Gemini returns structured JSON adhering to the application's strict response schema. If the AI service is unreachable, the server's fallback engine supplies a deterministic plan matching the event type and budget.
4. **Validation & Normalization:** The server normalizes the generated items, ensuring clean IDs, realistic percentage spreads, and safe strings.
5. **Interactive Management:** The client receives the plan, computes live budget arithmetic, persists the state to `localStorage`, and provides complete editing capabilities.

## Architecture

CelebrAI is structured as a full-stack web application with clean separation between client-side presentation and server-side execution:

- **Frontend:** Built with React 19 and TypeScript, styled using Tailwind CSS, and bundled with Vite. Component modules are organized around domain concerns (`budget`, `timeline`, `vendors`, `ideas`, `schedule`, `landing`).
- **Server:** Node.js Express server (`server.ts`) that handles API routing, proxying Gemini requests, payload validation, and serving the frontend application.
- **Server-Side API Key Management:** Sensitive credentials (`GEMINI_API_KEY`) remain strictly within the Node.js runtime and are never passed to or exposed in client bundles.
- **Deterministic Math Layer:** Budget totals, category percentages, remaining balances, and progress metrics are computed client-side using deterministic TypeScript helpers (`src/utils/currency.ts`).
- **Client Persistence:** Data is stored in browser `localStorage` (`src/utils/storage.ts`) with safe deserialization fallbacks to preserve customizations across sessions.

---

## AI Integration

- **Model:** `gemini-3.8-flash` via the official `@google/genai` TypeScript SDK.
- **Server-Side Proxy:** All AI operations occur through dedicated backend routes (`/api/plan/generate`, `/api/ideas/regenerate`). The browser client never interacts directly with Gemini endpoints.
- **Structured Schema Generation:** Requests utilize `responseSchema` and system instructions to ensure Gemini returns predictable, type-safe JSON matching the application's internal data models (`GeneratedPlanData`).
- **Safe Sanitization:** Incoming and outgoing strings are sanitized against excessive lengths and invalid data types before being passed to application state.
- **Fallback Resilience:** A deterministic fallback generator in `server.ts` handles recoverable API issues (such as rate limits or network hiccups), returning practical default celebration plans tailored to the requested event type.
- **Separation of Concerns:** Numerical calculations (e.g. summing expenses, remaining balance, overbudget flags) are computed through pure deterministic code rather than trusting LLM arithmetic.

## Security Considerations

The application implements defense-in-depth practices suitable for a web prototype:

- **Server-Side Secret Storage:** The `GEMINI_API_KEY` is loaded exclusively through server environment variables via `dotenv` and `process.env`. No API keys or tokens are embedded in frontend source files.
- **Strict Payload Limits:** Express body parsers enforce a strict `1mb` limit (`express.json({ limit: '1mb' })`) to defend against request payload abuse.
- **Input Validation & Boundary Checking:**
  - Event titles capped at 100 characters.
  - Guest counts constrained between 1 and 50,000.
  - Budgets constrained to positive numeric values up to 100,000,000.
  - Text fields sanitized and escaped before handling.
- **Type-Safe JSON Deserialization:** Local storage readers wrap JSON operations in defensive `try/catch` blocks with safe fallback states to prevent corruption-induced client crashes.
- **Clean Repository Hygiene:** Environment files containing secrets are ignored via `.gitignore`; only `.env.example` is committed with placeholder values.

*Future Production Considerations:* For high-scale production deployments, adding Redis-based rate limiting, user authentication (OAuth / JWT), and remote database persistence (e.g., PostgreSQL or Firestore) would further strengthen multi-user isolation.

## Local Development

Follow these steps to run CelebrAI locally:

### 1. Clone the repository

```bash
git clone https://github.com/souvikpal77/celebrai-event-planner.git
cd celebrai-event-planner
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Copy the example configuration file:

```bash
cp .env.example .env
```

Open `.env` in your text editor and provide your Gemini API key:

```env
GEMINI_API_KEY="your-gemini-api-key-here"
PORT=3000
```

### 4. Run the development server

```bash
npm run dev
```

The application will start on `http://localhost:3000`. The Express server automatically serves both the backend API and the Vite development middleware.

### 5. Build for production

To compile and verify the production build:

```bash
npm run build
```

To run the production server locally using `tsx`:

```bash
npm start
```

## Responsible AI & Planning Disclaimer

CelebrAI is an intelligent planning assistant designed to help hosts organize and conceptualize their events. 

- **Cost Estimates:** All generated budget allocations, expense amounts, and vendor estimates are planning approximations. They do not represent guaranteed market prices, binding quotations, or contractual commitments from vendors.
- **Vendor Logistics:** Vendor statuses and checklists are tools for host coordination and do not replace formal vendor agreements, permits, or venue inspections.
- **Professional Advice:** Suggestions provided by the AI do not constitute professional legal, financial, or safety advice. Event organizers should independently verify local safety ordinances, food handling guidelines, and venue fire codes.
